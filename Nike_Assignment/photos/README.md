# Photos for the report and slides

Put your own photos here with these exact names, then run `bash build/build_all.sh`.
Any photo that is missing is simply left out (no blank box).

| File name | What to photograph | Where it appears |
|---|---|---|
| `nike_cover.jpg` | A Nike Pegasus or Vegam Run shoe (portrait) | Report cover, Section 1.3, slide 3 |
| `nike_campaign.jpg` | A Nike running campaign poster or store window in India | Section 8.3 |
| `nike_shelf.jpg` | A multi-brand store's running wall showing Nike next to rivals | Section 9.3 |

Your own photos count as primary evidence and avoid copyright problems.
